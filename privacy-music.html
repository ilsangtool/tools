개인정보처리방침 (Privacy Policy)

시행일: 2026-11-19 · 운영자: 일상툴(ilsangtool)

1. 서비스 개요

music (YouTube 업로드 도구)는 운영자가 직접 제작한 음악 영상을 운영자 본인의 유튜브 채널에 업로드하기 위한 내부 자동화 도구입니다. 외부 이용자에게 제공되지 않습니다.

2. 수집·이용하는 정보

YouTube API Services를 통해 운영자 본인 계정의 인증 토큰만 사용하며, 영상 업로드·썸네일 설정·재생목록 추가에만 이용합니다. 다른 사용자의 개인정보는 수집하지 않습니다.

3. 보관 및 보호

인증 정보는 암호화된 저장소(GitHub Actions Secrets)에만 보관되며 제3자에게 제공하지 않습니다.

4. 권한 철회

운영자는 Google 계정 보안 설정(myaccount.google.com/permissions)에서 언제든 접근 권한을 철회할 수 있습니다.

5. 관련 약관

이 도구는 YouTube API Services를 사용합니다. YouTube 서비스 약관 및 Google 개인정보처리방침이 함께 적용됩니다.
